Pythonとファイルの準備

スクリプトを動かすための Python を入れ、スクリプト一式と国別データをひとつのフォルダにそろえます。

Python を入れる

  1. Windowsキーを押して cmd と入力し、「コマンドプロンプト」を開きます。
  2. 次のコマンドを貼り付けて、Enterキーを押します。
python --version

「Python 3.13.1」のように数字まで表示されれば、入っています。何も表示されない、または Microsoft Store が開いた場合は、まだ入っていません。

入れる場合は、Microsoft Store で「Python 3.13」を検索し、発行元が「Python Software Foundation」であることを確かめてから入手します。入れ終わったらコマンドプロンプトを開き直し、もう一度 python --version で確かめます。

追加のパッケージを入れる

グラフを描く matplotlib と、安全な通信のための truststore を入れます。

python -m pip install matplotlib truststore

最後に「Successfully installed」と表示されれば完了です。

スクリプト一式を入手する

  1. スクリプト一式（ZIPファイル）をダウンロードします。
  2. ダウンロードした dxcc-pilot-main.zip を右クリックし、「すべて展開」を選びます。
  3. 展開してできた dxcc-pilot-main フォルダを、C:\ の直下に移し、名前を dxcc-pilot に変えます。

この説明では、フォルダを C:\dxcc-pilot に置いたものとして進めます。別の場所に置いた場合は、以降のコマンドの C:\dxcc-pilot を読み替えてください。

国別データ（Big CTY）を置く

コールサインからエンティティを判定するために、AD1C Jim Reisert 氏が公開している Big CTY を使います。

  1. country-files.com の最新の記事から、「bigcty-年月日.zip」をダウンロードして展開します。
  2. 中にある cty.dat と cty.csv の2つを、C:\dxcc-pilot\common にコピーします。
  3. コピーした2つの名前を、それぞれ cty_latest.dat、cty_latest.csv に変えます。

名前を変える理由

HAMLOG のフォルダには、HAMLOG 自身が使う CTY.DAT があります。Windows はファイル名の大文字と小文字を区別しないため、同じ名前のままだと取り違えのもとになります。Big CTY は数か月ごとに新しくなるので、ときどき同じ手順で入れ替えてください。

名前を変えるときに拡張子が見えない場合は、エクスプローラーの「表示」→「表示」→「ファイル名拡張子」にチェックを入れます。

フォルダの中身

C:\dxcc-pilot
├─ dxcc_notify.py        通知スクリプトの本体
├─ notify_html.py        通知メール（HTML版）を作る
├─ hamlog_reader.py      HAMLOG の交信記録を読む
├─ hamlog_to_lotw.py     LoTW 提出用（必要な方のみ）
├─ dxcc_settings.py      設定ファイルを読む
├─ settings.ini          自局の設定（画面3で書きます）
├─ start_dxcc.bat        起動用ファイル（画面5で書きます）
├─ common
│   ├─ cty_latest.dat    ← 今置いたもの
│   └─ cty_latest.csv    ← 今置いたもの
└─ logs

ここまでの確認

  • python --version で、3.10 以上の版が表示される。
  • C:\dxcc-pilot\common に cty_latest.dat と cty_latest.csv がある。
