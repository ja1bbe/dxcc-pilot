通知の条件を決める

どのモード・どのバンドのスポットを知らせるか、全バンド初だけか、バンドニューも知らせるかを、settings.ini の [cluster] の欄で決めます。

[cluster] の欄を書く

C:\dxcc-pilot\settings.ini をメモ帳で開き、末尾の [cluster] の欄を、知らせてほしい条件に合わせて書き換えます。保存するときは、文字コードを「UTF-8」にします。

[cluster]
modes = FT8, CW, SSB
bands = all
notify = atno
sources = dxscape, dxsummit
interval_sec = 120
max_age_min = 30
renotify_hours = 6
max_per_hour = 10
項目意味書き方
modes知らせるモードFT8 FT4 CW SSB から選び、カンマで区切る
bands知らせるバンドall（全バンド）、または 160m, 80m のように並べる。選べるのは 160m・80m・60m・40m・30m・20m・17m・15m・12m・10m・6m
notify知らせる種類atno（全バンド初のみ）、または atno, bandnew（バンドニューも）
sourcesスポットの取得先dxscape と dxsummit の一方または両方
interval_sec取得の間隔（秒）60以上。既定は120
max_age_minこれより古いスポットは知らせない（分）既定は30
renotify_hours同じ局・同じバンド・同じモードを再び知らせるまでの時間既定は6
max_per_hour1時間に送る通知の上限既定は10

書き方の例

ローバンドの CW と FT8 だけ、バンドニューも知らせる

modes = FT8, CW
bands = 160m, 80m
notify = atno, bandnew

全バンドの FT8 で、全バンド初だけを知らせる

modes = FT8
bands = all
notify = atno

「全バンド初」は、どのバンドでもまだ交信していないエンティティです。「バンドニュー」は、ほかのバンドでは交信済みでも、スポットされたバンドではまだ交信していないエンティティです。バンドニューを加えると通知はかなり増えるので、まずは atno だけで始め、様子を見てから加えるのがおすすめです。

モードはどうやって決まるのか

DX クラスターのスポットには、モードの欄がありません。そのため、次の順番でモードを推定します。

  1. コメントに書かれた言葉：「FT8」「FT4」「CW」「SSB」「USB」「LSB」「RTTY」が書かれていれば、それを使います。
  2. デジタルモードの標準周波数：14074 kHz（FT8）や 14080 kHz（FT4）などから、+3 kHz までの範囲。
  3. バンド内の区分：各バンドの下の端の付近を CW、電話の区分を SSB とみなします（例：14000〜14070 kHz は CW、14100〜14350 kHz は SSB）。

どれにも当てはまらない周波数のスポットは、モードが分からないため知らせません。通知メールには「CW（周波数から推定）」のように、何から推定したかを表示します。

推定は目安です

バンドの区分は国や地域によって違い、DX ペディションは標準から外れた周波数で運用することもよくあります。たとえば FT8 の Fox/Hound 運用は、標準の周波数を外れていても、コメントに「FT8」と書かれていれば正しく判定できますが、コメントがないと CW や SSB と判定されたり、判定できなかったりします。

どの局のスポットを使うか

DXSCAPE の JA25 は、もともと日本からのスポットだけを集めたページです。DX Summit は、スポッターのコールサインを国別データ（Big CTY）で調べ、「Japan」と判定されたものだけを使います。小笠原（JD1）や南鳥島のスポッターは、DXCC では日本とは別のエンティティなので、使いません。
